# OBJEKTS Visual QC · Pilot 01

**Русскоязычный локальный технический preflight для партий изображений** — файлы проверяются в браузере без загрузки на сервер. Для брендов, агентств, e-commerce команд и каталожных продакшенов.

Live: https://objekts-visual-qc.objekts.chatgpt.site/
Studio: https://objekts.ai/ · Production inquiry: salute@objekts.ai

## Проверки

- Форматы JPG / PNG / WEBP, пустые и повреждённые файлы.
- Параметризованные минимальная ширина/высота и максимальный вес.
- Точные дубликаты по SHA-256, если доступен browser SubtleCrypto.
- Отсутствующие ракурсы при имени `SKU123__front.jpg` и обязательном списке `front,back,detail`.
- Экспорт локального CSV отчёта, без отправки изображения на сервер.

**Не проверяет** соответствие товара/одежды/украшений, цвет, посадку, художественное качество, модерацию WB/Ozon, прохождение клиентской приёмки или качество AI-генерации. Метка «Технически OK» ограничена указанными детерминированными правилами.

## Запуск и тесты

Откройте `dist/index.html` через локальный HTTP сервер (для ES modules). Тесты: `node --test tests/qc-core.test.mjs`. Развёртывание использует статический каталог `dist/`.

## Рабочий процесс

1. Подготовьте файлы, при необходимости с именами `SKU__ракурс.jpg`.
2. Выберите технические параметры под реальное ТЗ.
3. Запустите проверку. Просмотрите таблицу и экспортируйте CSV.
4. Отдельно выполните визуальную QC-приёмку с референсами.

## Privacy

Изображения обрабатываются в браузере. У этого релиза нет серверного endpoint для загрузки файлов, учётных записей или базы изображений. Переходы на сайт студии и email — внешние действия по выбору пользователя.
