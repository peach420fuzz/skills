# OBJEKTS Visual QC · проверка партии изображений

Бесплатный русскоязычный инструмент студии **objekts** для предварительной технической проверки файлов перед передачей в производство. Изображения выбираются на устройстве и обрабатываются в браузере. Отчёт сохраняется в CSV.

Студия: https://objekts.ai/ · Производственные задачи: salute@objekts.ai

## Запуск

Нужны Git, Python 3 и браузер. Сборщик, платный API и установка Python-пакетов не требуются.

```bash
git clone --depth 1 https://github.com/peach420fuzz/skills.git objekts-skills
cd objekts-skills/skills/objekts-visual-qc/assets/webapp
python3 -m http.server 8714 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8714/`. Сервер слушает только локальный адрес. Для остановки нажмите `Ctrl+C` в том же терминале.

В этой папке находятся `index.html`, `app.js`, `qc-core.js`, `README.md` и `LICENSE`. Каталог `dist/` не нужен. Набор автоматических тестов в эту папку не входит; прежняя команда с `tests/qc-core.test.mjs` была ошибочной.

## Проверка партии

Выберите до 200 изображений JPG, PNG или WebP за один запуск. Установите минимальные размеры и максимальный вес по техническому заданию. Для контроля комплектности используйте, например, `SKU123__front.jpg` и `SKU123__back.jpg`, а в поле ракурсов укажите `front,back`. Нажмите «Проверить партию», просмотрите замечания и сохраните CSV.

Проверяются формат по начальным байтам и его согласованность с расширением и MIME-типом, возможность прочитать изображение, разрешение, вес, точные дубликаты по SHA-256 и наличие названных ракурсов. Несколько разных файлов одного SKU и ракурса помечаются для ручного выбора утверждённой версии. Если SHA-256 недоступен, отчёт прямо сообщает, что проверка дубликатов не выполнена. Файлы сверх установленного лимита не декодируются и не хешируются целиком.

Параметры по умолчанию — технические ориентиры. Они не доказывают соответствие всем категориям Wildberries или Ozon. Результат «Технически OK» не подтверждает художественное качество, точность товара, ткани, посадки, украшения, цветопередачу или прохождение модерации. Наличие ракурса определяется по имени файла, а его содержание требует человеческой проверки.

## Исправление исходников · 9 ноября 2026

В `qc-core.js` и `app.js` связаны проверки сигнатуры файла и конфликтующих версий одного SKU/ракурса. Русская инструкция запуска приведена в соответствие с фактической структурой папки. Интерфейс и настраиваемые параметры сохранены.

При подготовке исправления выполнены 16 модульных и 14 локальных Chromium DOM-сценариев; по два в каждом наборе воспроизводят ошибки прежней версии. Локальный DOM-тест использовал отдельный адаптер SHA-256 для синтетических входов. Он не входит в исходники приложения и не подтверждает работу нативного браузерного хеширования, обычной загрузки ES-модулей или отдельного хостинга.

Исторический адрес отдельного развёртывания: https://objekts-visual-qc.objekts.chatgpt.site/ . В этом изменении хостинг не обновлялся. Его текущая доступность и совпадение с исходниками не подтверждены. Код на GitHub, отдельный сайт и установка навыка у агента имеют разные статусы.

## Производственная задача

objekts занимается AI/VFX, CGI и генеративным видеопроизводством. Для обсуждения исправления или создания визуального контента направьте на salute@objekts.ai объём партии, референсы, требования к результату и права на передаваемые материалы. Сайт студии: https://objekts.ai/ .

Выбор файлов в инструменте ничего не отправляет студии. Для обработки изображений приложение не использует серверную загрузку, учётные записи или внешние API; переходы на сайт и email выполняются по выбору пользователя. Изменение исходников не доказывает наличие пользователей, экономию времени или коммерческий результат.
