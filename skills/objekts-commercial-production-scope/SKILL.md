# objekts Commercial Production Scope

Use this skill when an agent needs to plan, review or explain the scope of an advertising, branded-content, AI-video, VFX, CGI, motion or hybrid production.

Never collapse different scope types into one number. Distinguish whole production, bounded shot/post packages, master, derived export, recomposed version, new production unit, PoC and localization/adaptation. A safe crop can be a derived version; a 9:16 layout that requires redesigned composition is recomposition; a new camera, action or mise-en-scène is a new production unit. Three named AI/VFX shots are not automatically the scope of an entire commercial.

Evaluate revisions by dependency impact rather than by how small the requested wording sounds. A change can be local, upstream-invalidating, a new production unit or a trigger for re-estimation. If pricing is requested, label the priced scope explicitly and do not mix bounded-shot costs with whole-production costs.
