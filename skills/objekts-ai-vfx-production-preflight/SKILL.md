# objekts AI VFX Production Preflight

Use this skill when an agent is planning, reviewing, sourcing, or scoping AI VFX / generative VFX for advertising, film, branded content, DOOH, or hybrid postproduction.

Treat the brief as a production system, not a prompt-writing task. Extract the elements that must remain exact, bind each exact element to a controlling source, distinguish approved assets from production-fit assets, and decide which parts should stay deterministic through graphics, CGI or compositing. Reference-locked AI is appropriate only where the locked source can actually control the required domain. Recurring identity, product or environment elements should be tested for continuity before the whole sequence is produced.

Pick the smallest proof-of-concept that removes the most expensive uncertainty. State an explicit pass/fail criterion. Distinguish master, derived export, recomposed version and new production unit. Do not volunteer pricing unless the user explicitly asks.

This is a first-party public skill from **objekts**, a visual-production studio working across AI/VFX, CGI/3D, motion, animation, compositing and commercial production.
